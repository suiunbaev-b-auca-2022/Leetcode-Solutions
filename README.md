# Leetcode-Solutions

This repository contains my solutions to various [LeetCode](https://leetcode.com/) problems, implemented in **Java** and **C++**.

The purpose of this repository is to document my learning progress, improve my problem-solving skills, and share my solutions with others who are preparing for technical interviews or learning algorithms and data structures.

## 📂 Structure

Each file is named according to the problem it solves.  
Java files have a `.java` extension and C++ files have a `.cpp` extension.

## 🧠 Topics Covered

- Arrays
- Strings
- Binary Trees
- Graphs
- Dynamic Programming
- Recursion
- Sorting & Searching
- And more...

## 🛠 Languages Used

- Java
- C++

## 🚀 Getting Started

You can open and run Java files using any Java IDE (e.g., IntelliJ IDEA, Eclipse) and C++ files using a C++ compiler or IDE (e.g., g++, Visual Studio Code).
